# Дайджест новостей и курсов → MAX

Автоматически 2 раза в сутки (08:00 и 20:00 **МСК**) отправляет в мессенджер MAX:

- Курсы ЦБ (USD, EUR, CNY)
- BTC и ETH
- Драгметаллы (золото, серебро, платина, палладий)
- Акции Мосбиржи
- 40 новостей (Интерфакс + BFM)

Работает **бесплатно** через GitHub Actions. ПК не нужен.

---

## Настройка (с телефона, 5 минут)

### 1. Создать бота в MAX
1. Откройте MAX → найдите **@MasterBot**
2. Нажмите «Начать» → `/create`
3. Придумайте имя → сохраните **токен**

### 2. Узнать chat_id
Напишите боту любое сообщение в MAX.

В браузере откройте (подставьте токен):
```
https://platform-api2.max.ru/updates?access_token=ВАШ_ТОКЕН
```
Найдите в ответе `"chat_id": число` — это ваш ID.

### 3. Добавить секреты в GitHub
1. Откройте этот репозиторий → **Settings** → **Secrets and variables** → **Actions**
2. **New repository secret**:
   - Name: `MAX_BOT_TOKEN` → Value: токен бота
   - Name: `MAX_CHAT_ID` → Value: ваш chat_id

### 4. Проверить вручную
1. Вкладка **Actions** → **MAX Digest** → **Run workflow** → **Run workflow**
2. Через ~30 секунд дайджест должен прийти в MAX

После этого бот будет сам слать сообщения каждое утро и вечер.

---

## Расписание

| Время МСК | UTC (GitHub) |
|-----------|--------------|
| 08:00     | 05:00        |
| 20:00     | 17:00        |

GitHub иногда запускает cron с задержкой до 15–30 минут — это нормально.
