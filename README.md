# Дайджест новостей и курсов → Telegram

Автоматически **2 раза в сутки** (08:00 и 20:00 МСК) отправляет в Telegram:

- Курсы ЦБ (USD, EUR, CNY)
- BTC и ETH
- Драгметаллы (золото, серебро, платина, палладий)
- Акции Мосбиржи
- 40 новостей (Интерфакс + BFM)

Работает **бесплатно** через GitHub Actions. ПК не нужен. Для физлиц — без ограничений.

Репозиторий: https://github.com/demospodkos/max-news-digest

---

## Настройка с телефона (5 минут)

### 1. Создать бота в Telegram
1. Откройте Telegram → найдите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте имя и username (должен заканчиваться на `bot`)
4. **Сохраните токен** вида `123456:ABC-DEF...`

### 2. Узнать свой chat_id
1. Напишите своему боту любое сообщение (например `/start`)
2. В браузере откройте (подставьте токен):
```
https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
```
3. Найдите `"chat":{"id": 123456789` — это ваш **chat_id** (число, может быть отрицательным для групп)

Альтернатива: напишите боту **@userinfobot** — он сразу покажет ваш id.

### 3. Добавить секреты в GitHub
1. Откройте репозиторий → **Settings** → **Secrets and variables** → **Actions**
2. **New repository secret**:
   - Name: `TELEGRAM_BOT_TOKEN` → Value: токен от BotFather
   - Name: `TELEGRAM_CHAT_ID` → Value: ваш chat_id

### 4. Проверить
1. Вкладка **Actions** → **Telegram Digest** → **Run workflow** → **Run workflow**
2. Через ~30–60 секунд дайджест придёт в Telegram

После этого сообщения будут приходить сами каждое утро и вечер.

## Расписание

| Время МСК | UTC |
|-----------|-----|
| 08:00     | 05:00 |
| 20:00     | 17:00 |

GitHub иногда запускает cron с задержкой 5–30 минут — это нормально.

## Про VPN на Севере

Telegram часто требует VPN. Если связь плохая:
- запасной вариант — email-рассылка (можно добавить);
- или SMS с краткими курсами (дорого и коротко).

Напишите, если нужен email-канал.
